# Sofra Printer releases

Public downloads for the shared Sofra Printer app: Windows x64/x86 executables and the signed Android APK.
The app connects to your restaurant and uses its name on receipts, with Sofra as the fallback.

For hosted restaurants, enter only the restaurant part of the Sofra address. For your own domain or server address, choose Custom domain.

Install Android updates over the existing app to retain the saved connection, device identity and print history.
Release binaries are built automatically from the private source repository on each version tag; source code stays private.
